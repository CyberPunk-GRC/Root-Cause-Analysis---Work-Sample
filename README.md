# Root-Cause-Analysis---Work-Sample
Root Cause Analysis – Server CPU Incident & SLA-171 Security Finding

This repository contains a Root Cause Analysis (RCA) report prepared in response to two related incidents:
1. Server CPU Incident
The application experienced performance degradation due to CPU utilization reaching 100%. Servers were restarted as an immediate fix. SRE and Dev teams are collaborating to identify the root cause (Ticket 12334).
2. SLA-19 Security Patch Compliance Finding
Security patches were flagged as unapplied on offline servers for two months. xyz company is investigating whether this is a genuine gap or a false positive (CS Ticket 202172).
